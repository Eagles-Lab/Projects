# 项目介绍

## 项目名称

云原生实战：基于 Kubernetes 构建 CI/CD 全自动流水线

## 项目背景

- 实验环境基于 VMware vSphere，采用三集群架构：工具集群（部署 Jenkins、GitLab、Harbor）、测试集群（开发测试环境）、生产集群（生产与预发布环境），另配备独立的 NFS 服务器与开发者机器。
- 模拟企业级 DevOps 场景：从产品需求、代码开发、编译打包到应用部署（dev → test → pre → prod）的完整软件交付生命周期。
- 业务侧采用 Flask（Python Web 框架）开发爬虫服务（豆瓣 Top250 等），通过 Gunicorn 作为 WSGI 服务器，使用 Docker 容器化后推送至 Harbor 镜像仓库，最终由 Jenkins Pipeline 自动部署至 Kubernetes 集群。
- 课程包含两位讲师的并行教学方案，分别从集群初始化与平台部署两个视角展开，最终均实现 GitLab + Jenkins + Harbor 的全自动 CI/CD 流水线。

## 项目价值

- 端到端交付能力：覆盖从 K8s 集群搭建、存储配置、Jenkins/GitLab/Harbor 平台部署到自动化流水线构建的完整链路，培养全流程 DevOps 工程化能力。
- 企业级流水线实践：通过 Jenkins 动态主从架构、多容器 PodTemplate、基于分支的环境隔离部署（develop → dev 命名空间，master → prod 命名空间）、交互式部署确认与一键回滚，掌握生产级 CI/CD 流水线的设计与优化方法。
- 容器化与镜像管理：掌握多阶段 Dockerfile 构建、Harbor 私有镜像仓库部署与管理、镜像版本_tag 策略（基于 Git Commit SHA），建立标准化制品管理流程。
- 代码质量与分支管控：通过 GitLab 分支保护、Pipeline 状态回写、合并前强制流水线成功检查等机制，确保代码质量门禁。
- 架构设计思维：三集群分离（工具/测试/生产）、NFS 持久化存储、StatefulSet 有状态服务管理、Ingress 域名路由等设计，为高可用与可扩展架构打下基础。
- 可扩展性：提供单元测试集成、SonarQube 代码扫描、冒烟测试等扩展方案，持续提升流水线成熟度。

## 技术栈

- 容器与编排：`Docker`、`Kubernetes (kubeadm v1.18.1)`
- 容器网络：`Flannel`、`Calico`
- 存储与配置：`NFS`、`PV/PVC`、`StorageClass`、`NFS Provisioner`、`Helm`
- CI/CD 平台：`Jenkins (LTS-JDK11)`、`GitLab (CE 15.0)`、`Harbor (v2.8.2)`
- 业务开发：`Flask`、`Gunicorn`、`Python 3.11`
- 流水线技术：`Jenkins Pipeline (Declarative)`、`Jenkinsfile`、`PodTemplate`、`GitLab Webhook`
- 环境与平台：`VMware vSphere`、`CentOS 7`

## 实战要求

1. 每节课按时完成课程任务与作业
2. 输出部署过程文档记录与验证截图

## 任务列表

### 第一课：集群初始化与平台部署

1. 完成 K8s 工具集群初始化（静态 IP、内核升级、Docker 安装、kubeadm 初始化、网络插件部署）
2. 部署 NFS 存储与 StorageClass，实现持久化动态供给
3. 在 K8s 上部署 Jenkins（StatefulSet + PVC + Ingress）
4. 在 K8s 上部署 GitLab（StatefulSet + ConfigMap + PVC + Ingress）

### 第二课：Jenkins 动态主从与应用开发

1. 配置 Jenkins Kubernetes 插件，实现动态 Slave Pod 创建
2. 配置 Docker-in-Docker，支持在 Pod 内执行 Docker 命令
3. 完成 Flask 爬虫项目开发（企业级项目结构、工厂模式、蓝图模块化）
4. 实现豆瓣 Top250 爬虫服务（工厂方法模式、多平台扩展）

### 第三课：Harbor 部署与服务容器化

1. 部署 Harbor 私有镜像仓库（Docker Compose 或 Helm 方式）
2. 编写生产级多阶段 Dockerfile（构建阶段 + 运行阶段）
3. 构建并推送 Flask 爬虫服务镜像至 Harbor
4. 在 K8s 上验证容器化服务运行正常

### 第四课：打通 GitLab 与 Jenkins 流水线

1. 配置 GitLab Webhook 触发 Jenkins 构建
2. 编写 Jenkinsfile（动态 PodTemplate：golang/docker/kubectl 容器）
3. 实现基于分支的环境隔离部署（develop → 测试集群，master → 生产集群）
4. 完成 Go 项目从代码提交到自动部署的完整流水线

### 第五课：流水线优化与 Python 项目实战

1. 添加生产部署交互式确认与一键回滚机制
2. 实现 GitLab 分支保护与 Pipeline 状态回写（合并前强制检查）
3. 适配 Python Flask 爬虫项目的 CI/CD 流水线
4. 优化 Jenkinsfile（try-catch 错误处理、内联 Dockerfile 生成、命名空间隔离部署）
5. [扩展] 集成单元测试（pytest）
6. [扩展] 集成 SonarQube 代码质量扫描
7. [扩展] 添加冒烟测试阶段

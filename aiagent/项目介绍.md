# 项目介绍

## 课程名称

大模型基础：构建 AI Agent for Kubernetes

## 适用对象

SRE 运维工程师及相关技术人员

## 课程目标

系统掌握大语言模型（LLM）的核心概念、提示词工程技术及 AI Agent 开发方法，具备构建面向 Kubernetes 运维场景的智能 Agent 的能力，实现 AI 与 SRE 工程的深度融合。

## 先修要求

具备基本的编程能力（Python）与运维知识（Linux、Kubernetes、Docker）。

## 项目背景

- AI 技术正加速渗透至各行各业，运维领域亦不例外。传统运维依赖人工编写告警规则、逐一排查日志、基于预设阈值做决策，而基于大模型的 AI 运维可实现自动关联历史案例、智能分析关键词、生成处理建议并辅助决策，将 MTTR（平均恢复时间）降低高达 90%。
- SRE 工程师在 AI 时代的核心定位并非成为算法专家，而是将成熟的 AI 能力模块化地嵌入现有运维体系——**AI 运维更多依赖工程落地能力而非算法研究能力**，SRE 的核心竞争力在于将 AI 模型作为基础设施组件整合到运维平台中。
- 本课程以"构建 AI Agent for Kubernetes"为主线：从大模型基础理论与提示词工程出发，通过 LangChain 和 Dify 掌握 Agent 开发方法，借助 MCP 协议实现与 K8s API 的标准化集成，最终在 Kubernetes 上部署并运行面向运维场景的智能 Agent——覆盖从 Agent 设计、开发、集成到生产部署的完整链路。
- 课程强调"认知融合"：理解 AI 的能力边界与运维场景的结合逻辑，聚焦日志智能分析、故障根因定位、告警降噪、自动化修复建议等 SRE 高频场景。

## 项目价值

- 理论筑基：系统掌握 Transformer 架构、注意力机制、预训练与微调（LoRA/QLoRA）、RLHF 等大模型核心技术原理，建立对 LLM 能力边界的准确认知。
- 提示词工程 mastery：掌握零样本/少样本提示、思维链（CoT）、自我一致性、结构化提示等高级技巧，学会设计高质量 Prompt 以精准控制模型输出，这是 LLM 应用开发中投入产出比最高的技能。
- 框架开发能力：通过 LangChain 掌握 LLM 应用工程化开发——链（Chain）、Agent、RAG（检索增强生成）、Memory、工具调用等核心抽象，具备构建复杂 LLM 应用的能力。
- 低代码平台实践：通过 Dify 平台的可视化工作流构建器，快速搭建 RAG 知识库问答、智能客服、运维知识助手等应用，实现从原型验证到生产部署的快速迭代。
- 协议与标准化：理解 MCP（Model Context Protocol）协议的设计理念与客户端-服务器架构，掌握"AI 的 USB-C"标准，实现 AI 模型与外部工具、数据源的标准化集成，解决 M×N 集成问题。
- AI Agent 与 Skills：理解 AI Agent 的自主决策机制与工具使用模式，掌握 Skills（可复用能力模块）的设计与开发，构建面向运维场景的智能 Agent 工作流。
- 运维场景落地：将上述能力综合应用于日志智能分析、故障根因定位、告警关联与降噪、Runbook 自动生成与执行等 SRE 实际场景，实现 AI 与运维的深度融合。

## 技术栈

- 大模型核心：`Transformer`、`GPT`、`BERT`、`LoRA/QLoRA`、`RLHF`、`Embedding`
- 提示词工程：`Zero-shot`、`Few-shot`、`Chain-of-Thought`、`Structured Prompting`
- 应用开发框架：`LangChain`、`LangGraph`、`LangSmith`
- LLMOps 平台：`Dify`
- 协议与标准：`MCP (Model Context Protocol)`
- AI Agent：`Agent`、`Skills`、`Tool Use`、`RAG (检索增强生成)`
- 容器与编排：`Docker`、`Kubernetes`
- 模型服务：`vLLM`、`TGI (Text Generation Inference)`
- 编程语言：`Python`
- 向量存储：`Milvus`、`Chroma`、`FAISS`

## 章节大纲

### 第一章 导论：AI 时代与 SRE 的定位

1. **背景与动机**：AI 技术加速渗透运维领域，SRE 需明确在 AI 时代的定位与核心价值——工程落地能力是 AI 与运维深度融合的关键纽带
2. **传统运维与 AI 运维对比**：从规则来源、故障分析、决策方式、工程师角色四个维度对比传统运维与 AI 运维的差异
3. **SRE 在 AI 时代的核心方向**：基础能力层（夯实运维开发核心技能）、认知融合层（理解 AI 能力边界与运维结合逻辑）、实践应用层（将 AI 工具集成至运维平台）

### 第二章 大模型基础理论

1. **从机器学习到大模型**：监督/无监督学习、神经网络、深度学习演进路线
2. **Transformer 架构**：自注意力机制、多头注意力、位置编码、编码器-解码器结构
3. **大模型训练流程**：预训练（Pre-training）、有监督微调（SFT）、RLHF（基于人类反馈的强化学习）
4. **模型推理与优化**：量化（Quantization）、蒸馏（Distillation）、推理加速（vLLM/TGI）
5. **主流模型概览**：GPT 系列、Claude 系列、开源模型（LLaMA、Qwen、DeepSeek）
6. **Agent 视角**：理解 LLM 如何作为 Agent 的"大脑"进行推理、规划与工具调用

### 第三章 提示词工程

1. **基础技术**：零样本提示、少样本提示、模板设计、变量注入
2. **高级技术**：思维链（Chain-of-Thought）、自我一致性（Self-Consistency）、元提示（Meta-Prompting）
3. **结构化提示**：系统提示设计、角色设定、输出格式控制、JSON/Markdown 结构化输出
4. **参数调优**：Temperature、Top-K、Top-P 对输出质量与创造力的影响
5. **运维场景实战**：日志分析提示词、故障诊断提示词、告警摘要提示词的设计与优化

### 第四章 LangChain 应用开发

1. **核心概念**：Model、Prompt Template、Output Parser、Chain
2. **记忆与上下文**：Conversation Memory、Summary Memory、向量检索上下文
3. **工具与 Agent**：Tool 定义、ReAct 模式、自定义 Agent、多工具编排
4. **RAG 检索增强生成**：文档加载、分块策略、向量存储、语义检索、生成回答
5. **LangGraph 多 Agent**：有状态图、节点与边、条件路由、人机协作工作流
6. **运维场景实战**：构建运维知识库问答系统、日志智能分析 Agent

### 第五章 Dify 平台与 LLMOps

1. **Dify 平台概览**：架构设计、核心功能、与 LangFlow/Coze 对比
2. **可视化工作流**：拖拽式 Agent 编排、多步骤 AI 流程设计、条件分支与循环
3. **RAG 知识库**：文档摄取、分块与索引、混合检索策略、回答质量评估
4. **模型管理**：多模型统一接入（OpenAI/Anthropic/本地模型）、模型路由与降级
5. **API 与集成**：Dify API 调用、Webhook 触发、与现有运维平台集成
6. **运维场景实战**：搭建运维告警智能分析平台、故障自愈知识库

### 第六章 MCP 协议与标准化集成

1. **MCP 协议概述**：设计理念（"AI 的 USB-C"）、解决的问题（M×N 集成）、与 Function Calling 对比
2. **架构详解**：Host-Client-Server 模型、工具（Tools）、资源（Resources）、提示模板（Prompts）
3. **MCP Server 开发**：基于 FastMCP/TypeScript SDK 开发自定义 MCP Server
4. **传输与安全**：stdio 本地通信、HTTP/SSE 远程通信、认证与权限控制
5. **运维场景实战**：开发 K8s 运维 MCP Server（Pod 管理、日志查询、指标监控）

### 第七章 AI Agent 与 Skills 开发

1. **Agent 设计模式**：ReAct、Plan-and-Execute、多 Agent 协作、层级式 Agent
2. **Skills 架构**：SKILL.md 规范、参考文档、脚本集成、能力描述与触发机制
3. **工具集成**：自定义工具开发、MCP 工具调用、API 集成、命令行工具封装
4. **多 Agent 工作流**：任务分解、Agent 间通信、结果聚合、人机协作节点
5. **运维场景实战**：构建 K8s 故障自愈 Agent（告警触发 → 日志分析 → 根因定位 → 自动修复）

### 第八章 综合实战：构建 K8s 智能运维 Agent

1. **需求分析与架构设计**：梳理 K8s 运维痛点、定义 Agent 能力边界、设计多 Agent 协作架构
2. **K8s MCP Server 开发**：封装 kubectl、日志查询、指标监控、事件监听为 MCP 工具
3. **Agent 编排与 Skills 定义**：告警分诊 Agent、根因分析 Agent、修复执行 Agent 的 Skills 设计
4. **K8s 部署与运行**：Agent 服务容器化、RBAC 权限配置、与 K8s 事件系统的集成
5. **安全与治理**：操作审批流、危险操作防护、操作审计与回滚机制
6. **实战验收**：端到端演示——K8s 故障发生 → Agent 自动感知 → 多 Agent 协作分析 → 生成修复方案 → 人工审批 → 自动执行修复
